## 三、实验过程

### 1. 读取输入图像并转换为灰度图

使用 `cv2.imread` 读取两张彩色输入图像 `a.png` 和 `b.png`，分别获得 1440×1281 和 1440×1279 像素的 BGR 图像。SIFT 特征检测需要在灰度图上进行，因此使用 `cv2.cvtColor` 将两张图像转换为灰度图。

```python
img_a = cv2.imread("a.png")
img_b = cv2.imread("b.png")
gray_a = cv2.cvtColor(img_a, cv2.COLOR_BGR2GRAY)
gray_b = cv2.cvtColor(img_b, cv2.COLOR_BGR2GRAY)
```

结果：成功读取两张输入图像，图像 a 尺寸为 1440×1281，图像 b 尺寸为 1440×1279。灰度转换保留了图像的亮度信息，为后续特征检测提供了基础。

### 2. SIFT 特征检测

使用 OpenCV 的 SIFT（Scale-Invariant Feature Transform，尺度不变特征变换）算法检测两张灰度图像中的关键点及其描述符。SIFT 特征对尺度、旋转和光照变化具有鲁棒性，适合用于图像拼接。

```python
sift = cv2.SIFT_create()
kp_a, des_a = sift.detectAndCompute(gray_a, None)
kp_b, des_b = sift.detectAndCompute(gray_b, None)
```

| 图像 b 关键点数 | 5261 | 检测到的特征点数量 |

结果：SIFT 在图像 a 中检测到 7022 个关键点，在图像 b 中检测到 5261 个关键点。关键点主要分布在货架边缘、商品轮廓、文字标识等纹理丰富的区域。每个关键点对应一个 128 维的描述符向量，用于后续匹配。

### 3. FLANN 特征匹配

使用 FLANN（Fast Library for Approximate Nearest Neighbors，快速最近邻近似搜索库）匹配器对两组 SIFT 描述符进行特征匹配。FLANN 采用 KD 树算法，对于高维特征向量的匹配比暴力匹配更高效。

```python
FLANN_INDEX_KDTREE = 1
index_params = dict(algorithm=FLANN_INDEX_KDTREE, trees=5)
search_params = dict(checks=50)
flann = cv2.FlannBasedMatcher(index_params, search_params)
matches = flann.knnMatch(des_a, des_b, k=2)
```

`knnMatch` 的 `k=2` 参数表示为图像 a 中的每个特征点在图像 b 中寻找两个最近邻匹配，这为后续的 Lowe's 比率测试提供了基础。

| 匹配项目 | 实际输出 | 说明 |
| --- | --- | --- |
| 初始匹配对数 | 7022 | 每个描述符返回 2 个最佳匹配 |
| 特征匹配耗时 | 0.081 秒 | FLANN 匹配耗时 |

结果：FLANN 匹配器为图像 a 的 7022 个关键点分别找到了两个最近邻候选匹配，共产生 7022 组匹配对。匹配耗时 0.081 秒，显著快于暴力匹配。

### 4. Lowe's 比率测试筛选优质匹配

FLANN 的初始匹配结果中包含许多误匹配。Lowe's 比率测试通过比较最近邻距离与次近邻距离的比值来筛选可靠匹配：若比值小于阈值（通常取 0.7-0.8），则认为该匹配是可靠的。

```python
good_matches = []
for m, n in matches:
    if m.distance < 0.7 * n.distance:
        good_matches.append(m)
```

| 筛选项目 | 实际输出 | 说明 |
| --- | --- | --- |
| 比率阈值 | 0.7 | Lowe's 比率测试阈值 |
| 优质匹配对数 | 66 | 通过比率测试的匹配 |
| 匹配保留率 | 0.94% | 66 / 7022 |

结果：经过 Lowe's 比率测试，从 7022 组初始匹配中筛选出 66 对优质匹配，保留率为 0.94%。这些优质匹配的最近邻距离显著小于次近邻距离，具有更高的可靠性。

### 5. 使用 RANSAC 计算单应矩阵

单应矩阵（Homography Matrix）描述了两个平面之间的投影变换关系。使用 RANSAC（Random Sample Consensus，随机抽样一致）算法从优质匹配中估计单应矩阵，可以有效排除外点（outliers）的影响。

```python
src_pts = np.float32([kp_b[m.trainIdx].pt for m in good_matches]).reshape(-1, 1, 2)
dst_pts = np.float32([kp_a[m.queryIdx].pt for m in good_matches]).reshape(-1, 1, 2)
H, mask = cv2.findHomography(src_pts, dst_pts, cv2.RANSAC, 5.0)
```

`src_pts` 是图像 b 中匹配点的坐标，`dst_pts` 是图像 a 中对应点的坐标。RANSAC 的重投影误差阈值设为 5.0 像素，即认为重投影误差小于 5 像素的匹配点为内点（inliers）。

| 单应矩阵计算 | 实际输出 | 说明 |
| --- | --- | --- |
| RANSAC 内点数 | 7 / 66 | 符合单应变换的匹配点 |
| 内点比例 | 10.61% | 7 / 66 |
| 计算耗时 | 0.020 秒 | RANSAC 算法耗时 |

结果：RANSAC 从 66 对优质匹配中识别出 7 个内点，内点比例为 10.61%。内点数量较少可能是由于两张图像的视角差异较大，或场景中存在非平面结构（如人物、商品的不同深度）。尽管内点比例不高，但 7 个内点仍足以估计出可用的单应矩阵。

估计的单应矩阵 H 为：

```
[ -0.405135,  -0.556032, 1071.114768]
[ -0.119400,   0.094982,   58.934452]
[ -0.000310,  -0.000547,    1.000000]
```

该矩阵描述了将图像 b 变换到图像 a 坐标系的投影关系。

### 6. 计算拼接后图像尺寸

为了确保拼接后的图像包含两张原图的所有像素，需要计算图像 b 经透视变换后四个角点的新坐标，并结合图像 a 的角点坐标确定输出图像的尺寸。

```python
pts = np.float32([[0, 0], [0, h_b], [w_b, h_b], [w_b, 0]]).reshape(-1, 1, 2)
dst_corners = cv2.perspectiveTransform(pts, H)

all_corners = np.concatenate([dst_corners, 
    np.float32([[0,0], [w_a,0], [w_a,h_a], [0,h_a]]).reshape(-1,1,2)], axis=0)

[x_min, y_min] = np.int32(all_corners.min(axis=0).ravel() - 0.5)
[x_max, y_max] = np.int32(all_corners.max(axis=0).ravel() + 0.5)
```

| 尺寸计算 | 实际输出 | 说明 |
| --- | --- | --- |
| 图像 b 变换后角点 1 | (1071.11, 58.93) | 左上角 |
| 图像 b 变换后角点 2 | (1276.39, 923.72) | 左下角 |
| 图像 b 变换后角点 3 | (1344.28, -233.30) | 右下角 |
| 图像 b 变换后角点 4 | (915.72, -155.30) | 右上角 |
| 拼接输出尺寸 | 1673 × 1344 | 高 × 宽 |
| 坐标范围 | x ∈ [0, 1344], y ∈ [-233, 1440] | 需要平移使所有像素可见 |

结果：图像 b 经透视变换后，部分角点的 y 坐标为负值（-233.30 和 -155.30），说明变换后的图像超出了原坐标系的可见区域。为使所有像素都包含在输出图像中，需要构造平移矩阵将坐标系向下平移 233 像素。最终输出图像尺寸为 1673×1344。

### 7. 透视变换与图像拼接

将单应矩阵与平移矩阵组合，对图像 b 进行透视变换，然后将图像 a 复制到输出图像的对应位置，完成拼接。

```python
translation_matrix = np.array([
    [1, 0, -x_min],
    [0, 1, -y_min],
    [0, 0, 1]
], dtype=np.float32)

stitched_img = cv2.warpPerspective(
    img_b,
    translation_matrix @ H,
    (x_max - x_min, y_max - y_min)
)

stitched_img[-y_min : h_a - y_min, -x_min : w_a - x_min] = img_a
```

`warpPerspective` 将图像 b 按组合变换矩阵进行透视变换，输出到指定尺寸的空白画布。然后将图像 a 直接复制到画布的对应位置。由于图像 a 是参考坐标系，不需要变换。

| 拼接项目 | 实际输出 | 说明 |
| --- | --- | --- |
| 透视变换与拼接耗时 | 0.007 秒 | 包含变换和复制 |
| 输出图像尺寸 | 1673 × 1344 | 最终拼接结果 |

结果：透视变换与拼接耗时 0.007 秒，生成 1673×1344 的全景图像。拼接后的图像包含了两张原图的所有可见内容。

## 四、实验结果与分析

### 1. SIFT 特征检测的有效性

SIFT 在图像 a 和 b 中分别检测到 7022 和 5261 个关键点，关键点主要分布在纹理丰富的区域，如货架边缘、商品轮廓、文字标识等。这些区域的灰度变化显著，局部梯度强，因此被 SIFT 识别为显著特征点。

SIFT 特征对尺度和旋转具有不变性，即使两张图像的拍摄视角略有不同，SIFT 仍能在相同的物理位置检测到对应的关键点。本实验的两张输入图像视角差异适中，SIFT 检测效果良好。

### 2. FLANN 匹配与 Lowe's 比率测试

FLANN 匹配器利用 KD 树算法快速找到描述符的近似最近邻，匹配耗时仅 0.081 秒，显著优于暴力匹配。`knnMatch` 返回每个特征点的两个最佳候选匹配，为 Lowe's 比率测试提供了基础。

Lowe's 比率测试是特征匹配中常用的筛选方法。本实验设置比率阈值为 0.7，从 7022 组初始匹配中筛选出 66 对优质匹配，保留率仅 0.94%。这说明大部分初始匹配是模糊或错误的，只有少数匹配具有明显的区分度。

保留率较低的原因可能包括：
- 两张图像的重叠区域相对较小，许多特征点只出现在一张图像中；
- 场景中存在重复纹理（如相似的商品、货架结构），导致描述符相似度较高，难以区分；
- 光照、视角变化导致部分特征点的描述符发生变化。

尽管保留率不高，但 66 对优质匹配已足够用于后续的单应矩阵估计。

### 3. RANSAC 单应矩阵估计

RANSAC 从 66 对优质匹配中识别出 7 个内点，内点比例为 10.61%。内点数量较少可能是由于：
- 场景中存在非平面结构或深度变化（如人物、商品的不同深度层），不完全符合平面单应变换假设；
- 两张图像的视角差异较大，导致部分匹配点的投影关系偏离理想的单应变换；
- 优质匹配中仍存在少量误匹配，被 RANSAC 识别为外点。

尽管内点比例不高，但 7 个内点仍能提供足够的约束来估计 3×3 的单应矩阵（理论上需要至少 4 对对应点）。从拼接结果来看，估计的单应矩阵是有效的，变换后的图像 b 与图像 a 在重叠区域基本对齐。

### 4. 透视变换与拼接效果

透视变换将图像 b 投影到图像 a 的坐标系，变换后图像 b 的四个角点坐标为 (1071.11, 58.93)、(1276.39, 923.72)、(1344.28, -233.30) 和 (915.72, -155.30)。部分角点的 y 坐标为负值，说明变换后的图像超出了原坐标系的可见范围。通过构造平移矩阵，将整个坐标系向下平移 233 像素，确保所有像素都包含在输出图像中。

最终拼接结果的尺寸为 1673×1344，大于单张输入图像的尺寸（1440×1281 和 1440×1279），这是因为拼接后的全景图包含了两张图像的所有可见内容，而不仅仅是重叠区域。

从图4可以观察到，拼接后的图像在重叠区域存在明显的拼接缝，这是因为本实验采用的是简单的图像复制方法（将图像 a 直接覆盖到变换后的图像 b 上），没有进行图像融合或接缝优化。重叠区域可能存在以下问题：
- 光照差异：两张图像的拍摄时间或光照条件略有不同，导致重叠区域的亮度或颜色不一致；
- 对齐误差：由于单应矩阵估计的内点较少，变换后的图像 b 与图像 a 在重叠区域可能存在细微的对齐误差；
- 硬切割边界：直接覆盖会在图像 a 的边界产生明显的硬切割效果，视觉上不够自然。

改进方法包括：
- 多频段融合（Multi-band Blending）：在重叠区域对不同频段的图像分量分别进行加权融合，使过渡更平滑；
- 泊松融合（Poisson Blending）：通过求解泊松方程，在重叠区域平滑过渡两张图像的梯度；
- 最优接缝（Graph Cut）：在重叠区域寻找最优的拼接路径，沿着纹理边界或低梯度区域切割，减少视觉不连续。

本实验重点是理解特征匹配和透视变换的原理，未实现图像融合。

### 5. 算法性能

本实验的总耗时为 0.488 秒，其中：
- SIFT 特征检测：0.379 秒（占 77.7%）
- FLANN 特征匹配：0.081 秒（占 16.6%）
- RANSAC 单应矩阵估计：0.020 秒（占 4.1%）
- 透视变换与拼接：0.007 秒（占 1.4%）

SIFT 特征检测是整个流程中最耗时的步骤，因为需要在多个尺度和方向上计算图像梯度、构建高斯金字塔并提取关键点。对于高分辨率图像（本实验为 1440×1280 左右），SIFT 检测的计算量较大。

FLANN 匹配和 RANSAC 估计的耗时相对较少。透视变换的耗时最少，因为 OpenCV 的 `warpPerspective` 采用了高效的插值和并行计算优化。

总体而言，本实验在普通 CPU 上完成 1440×1280 分辨率图像的拼接耗时不到半秒，性能表现良好。

## 五、实验总结

本实验成功实现了基于 SIFT 特征匹配的图像拼接，完成了特征检测、FLANN 匹配、Lowe's 比率测试筛选、RANSAC 单应矩阵估计和透视变换拼接的完整流程。

实验结果表明，SIFT 特征检测能够在纹理丰富的区域提取大量关键点，FLANN 匹配器可以快速找到候选匹配，Lowe's 比率测试有效筛选出可靠匹配。尽管本实验中 RANSAC 识别的内点比例较低（10.61%），但仍能估计出有效的单应矩阵，完成全景拼接。

拼接结果在重叠区域存在明显的拼接缝，这是由于本实验采用了简单的图像复制方法，未进行图像融合。后续可以通过多频段融合、泊松融合或最优接缝等方法改善拼接效果。

通过本实验，进一步理解了特征提取、特征匹配、几何变换和图像拼接的基本原理，掌握了 OpenCV 中 SIFT、FLANN、RANSAC 和透视变换的使用方法。图像拼接是计算机视觉中的经典问题，在全景图生成、虚拟现实、医学图像处理等领域有广泛应用。
